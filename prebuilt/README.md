# Prebuilt firmware inputs

Everything in this directory comes from one stock Xiaomi 15T (`goya`) firmware
release. Do not mix files from different builds.

## What is committed

| Path | Source | Notes |
| --- | --- | --- |
| `vendor-boot/header.json` | `vendor_boot.img` header | v4 ramdisk table, addresses and sizes |
| `vendor-boot/vendor_ramdisk00` | type-1 platform fragment | stock normal-boot userspace, fstab, firmware and vendor_ramdisk modules |
| `vendor-boot/vendor_ramdisk01+` | any extra non-recovery stock fragment | passed through unchanged by the repacker. The stock recovery fragment itself is dropped after `modules.load.recovery` has been read, because the OrangeFox fragment replaces it. |
| `vendor-boot/modules.load.recovery` | stock platform fragment (`vendor_ramdisk00`) | first-stage recovery module list reused by `fox_callback.sh`; includes the MTK IPI/RPMSG mailbox modules missing from the normal `modules.load`. The recovery fragment is used only as a fallback for layouts that keep the list there. |
| `vendor-boot/dtb` | DTB from `vendor_boot.img` | MediaTek-wrapped FDT, kept byte-identical |
| `vendor-boot/bootconfig` | vendor bootconfig | may be empty |
| `health/android.hardware.health-service.example_recovery` | `vendor_boot.img` platform fragment | compact AIDL Health HAL started by `init.recovery.mt6899.rc` as `health-aidl`; fastbootd waits for `android.hardware.health.IHealth/default`. Extracted by `prepare-stock-vendor-boot.sh`. |
| `dtb/mt6899-goya.dtb` | copy of `vendor-boot/dtb` | consumed by the build and repacker |
| `modules/*.ko` | stock `vendor_dlkm` | `xiaomi_touch_goya.ko`, `nt38771_touch_goya.ko`, `si_haptic.ko`, `scp.ko` |
| `vendor_boot_stock.sha256` | full stock image | provenance checksum only |

`prebuilt/vendor_boot_stock.img` (117440512 bytes) is intentionally ignored by
Git. It is useful locally for re-extraction but exceeds a comfortable
repository size.

## How to populate

From a rooted phone with adb:

```bash
tools/dump-stock-goya.sh goya-dump.tar
tools/import-dump.sh goya-dump.tar
```

From a firmware package, extract `vendor_boot.img` and run:

```bash
tools/prepare-stock-vendor-boot.sh /path/to/vendor_boot.img
```

The platform fragment is mandatory. Without it the repacker cannot produce a
bootable vendor_boot image: the kernel repository has none of the
vendor_ramdisk display, UFS and USB modules.

## Hash manifest

`manifests/device-blobs.sha256` records every imported file under
`prebuilt/vendor-boot`, `prebuilt/dtb`, `prebuilt/modules` and `proprietary`.
It is regenerated by `tools/import-dump.sh` and checked by
`tools/verify-build-inputs.sh`.
